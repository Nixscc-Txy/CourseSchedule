# 导入课表

课表数据有两个来源，**导入的优先**：

1. **用户导入的课表** —— 存在 App 私有目录 `files/imported_schedule.json`，在手机上通过「导入课表」写入
2. **内置课表** —— `app/src/main/assets/schedule.json`，**出厂是空的**（`courses` 为空数组），只有想预置课表进 APK 时才需要动它

---

## 方式一：手机上直接导入（推荐）

不需要电脑，也不需要这个仓库。

1. 从教务系统下载课表文件（微信/QQ 转发过来的也行）
2. 打开 App → 顶部 ⚙ → 「📥 导入课表」
3. 在文件选择器里找到那个文件（通常在"下载"目录）
4. 确认弹窗会显示解析出的课程数与周数；如果课表里有平行选修冲突，会让你先挑课
5. 点「导入」→ 课表立即生效，桌面小组件同步更新

**支持的文件：**

| 格式 | 说明 |
|---|---|
| 教务系统矩阵式 `.xls` | 行=时间段、列=星期、单元格内是课程信息 |
| 同上但存成 `.xlsx` | 微信/QQ 传过来常是这种（扩展名可能不符，内容是 xls 也能识别） |
| `schedule.json` | 本仓库定义的格式，见 [数据格式](data-format.md) |

解析全部由 App 内置代码完成（`XlsReader.kt` 是手写的 OLE2/BIFF8 读取器），**不依赖任何第三方库**，所以装完即可离线使用。

导错了？重新导入正确文件即可覆盖。想彻底清空：设置页「🗑 清空课表」。

---

## 方式二：电脑上生成 JSON

适合开发者，或课表格式比较特殊、需要先转换的情况。生成后有两种用法：

- 把 `schedule.json` 传到手机上，用 App 的「导入课表」导入
- 或替换 `app/src/main/assets/schedule.json` 后重新构建，把它预置进 APK

### 2.1 列式课表（一行一门课）

适用于有独立「星期 / 节次 / 周次 / 教师 / 教室」列的表格。

> ⚠️ 只支持**新版 `.xlsx`** —— 脚本用的 openpyxl 读不了旧版 `.xls`。若学校导出的是 `.xls`，用下面的矩阵式脚本，或先用 Excel 另存为 `.xlsx`。

`@bash
cd tools
pip install openpyxl

# 1) 先看列对应关系
python excel_to_json.py 你的课表.xlsx --inspect

# 2) 按确认的列号转换
python excel_to_json.py 你的课表.xlsx \
  --day-col 3 --slot-col 1 --name-col 2 \
  --week-col 5 --teacher-col 6 --room-col 7 \
  --total-weeks 19 \
  -o ../app/src/main/assets/schedule.json
`@

### 2.2 矩阵式课表（教务系统导出）

「行=时间段、列=星期、单元格内含课程信息」的格式，例如：

`@
数据结构/(1-2节)1-16周/中心校区 教学楼412/李老师/数据结构-0003/4.0
`@

`@bash
cd tools
pip install xlrd
python matrix_xls_to_json.py 你的课表.xls -o ../app/src/main/assets/schedule.json
`@

> 该脚本读 `.xls`；如果学校导出的是 `.xlsx` 但打开报错，通常内容仍是 `.xls`（扩展名不符），直接传入即可。

## 冲突选课是怎么回事

教务系统导出的**班级课表**里，同一个时段往往平行开着好几门选修课（别人要上的）。App 不会替你删掉任何一门，而是在导入时把这种时段整理成「冲突簇」让你回答：

- 从若干门里挑出**你实际上**的那门
- 或者选「**这组我都不上**」
- 同一批课在多天同一时段同时开设时，**只会问你一次**，答案自动套用到所有相关时段

规则细节：冲突以「**课程名 + 教师 + 教室**」作为一门课的身份。同一门课因周次/教室不同被导出成多条记录时视为同一个选项，选它则所有相关记录都保留。

导入后如果还有没解决的冲突，课表顶部会提示「有 N 处时间冲突还没选」并给出补选入口 —— 不需要重新导入文件。

## 学期切换

每个新学期只需要：

1. 更新课表：手机上重新导入新的课表文件（或替换 `schedule.json` 后重新构建）
2. 到设置页改「学期开学日期」
3. App 会按当前日期自动算出当前周
